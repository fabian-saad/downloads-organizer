# Downloads Organizer

A simple Go script that automatically cleans up the Downloads folder by organizing files into categorized subfolders based on their extension.

## Prerequisites

Go 1.21 or newer

## Usage

Clone or download the repository.

```bash
git clone https://github.com/fabian-saad/downloads-organizer.git
cd downloads-organizer

```

Run the script in your terminal:

```bash
go run main.go

```

Or build an executable:

```bash
go build -o downloads-organizer.exe

```
